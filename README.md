# Onni · Laboratório do anel

Página para conectar o anel QRing (Colmi R09) pelo Bluetooth do Chrome e conferir os dados, antes de levar para o app Onni.

## Testar o anel agora (sem instalar nada)

1. Carregue o anel.
2. No celular, feche o app QRing ou desligue o Bluetooth.
3. Abra o arquivo `lab/saida/index.html` no Chrome do computador.
4. Clique em "Conectar anel" e escolha o R09_F301.
5. Se algo der errado, clique em "Copiar relatório" e cole na conversa com o Claude.

## Continuar no Claude Code

1. Coloque esta pasta num repositório do GitHub (por exemplo `onni-laboratorio-anel`).
2. Abra o Claude Code com esse repositório (no computador ou em claude.ai/code).
3. Primeira mensagem sugerida: "Leia o CLAUDE.md e me ajude a testar o anel."

O arquivo `CLAUDE.md` tem todo o contexto: decisões, regras, comandos e o que falta.
